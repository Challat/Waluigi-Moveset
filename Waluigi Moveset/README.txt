
Please ensure you have all below dependencies UP TO DATE!!

Arcropolis - https://github.com/Raytwo/ARCropolis
Skyline - https://github.com/skyline-dev/skyline

NRO Hook - https://github.com/ultimate-research/nro-hook-plugin/releases
Smashline2 - https://github.com/HDR-Development/smashline
Param Config plugin - https://github.com/CSharpM7/lib_paramconfig
One Slot Effects - https://gamebanana.com/mods/549058


The new CSK Collection allows it so you dont need the CSS Manager to merge moveset mods.
However, if you have installed CSKs CSS Manager tool and would like to move where Waluigi shows on your css, use the below details
Duplicate Terry
Character ID: ui_chara_waluigi (yes it is case sensitive)
Name ID: waluigi (yes it is case sensitive)
Amount of Colors: 8
Color Start Index: 120
